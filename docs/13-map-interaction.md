# 地图选择与照片可发现性

## 问题与验收目标

原先地图使用 6px 圆点，点击后相机下降至约 120km；Natural Earth 全球影像在该尺度模糊。密集点容易误选，照片是否存在也只能打开档案后确认。

本次改动使地图、列表、档案使用同一个路由选中 ID。每座火山都可打开基础档案；是否包含已核验照片单独表达，不能把缺照片误写为缺档案。

## 实现步骤

1. `src/domain/mapInteraction.ts` 定义形态 SVG、相机高度与安全拾取函数。复合火山用高锥、盾状火山用低缓轮廓、破火山口用凹陷顶部、火山群用多锥、其他用不规则轮廓。小型火山单独用小锥，不把所有 Minor 分类称为火山渣锥。
2. SVG 全部内嵌路径，供 Cesium billboard、列表和地图图例共用。原教学图解及对照表继续保留；地图轮廓是独立矢量示意，不代表真实尺度。相机徽章代表目录含已核验照片，不承诺网络图片永远可用。
3. 普通地图图标为 20×18px，选中为 28×25px，选中山体改为亮黄色填充与白色描边，并添加金色四角、火山名称及固定选中提示。地图保留被筛选隐藏的已选火山，避免档案与地图指向不一致。
4. `drillPick` 使用 32×32px 容错窗口，去重并过滤非火山实体。只有一个候选时直接选择；多个候选时提供明确列表，有照片优先，不擅自选择最上层。悬停提示名称与照片状态，鼠标指针提示可点击；悬停拾取节流为 100ms。
5. 相机选择高度限制在 2,500,000–5,000,000m；手动缩放下限 1,500,000m。这是针对当前全球影像的产品取舍，不用于近距离地形测量。
6. 列表默认有照片优先，照片组与无照片组内分别按 GVP 编号升序，提供“只看有照片”复选框、每项照片状态和分页加载。筛选不改变原始官方目录。
7. 点击后立即显示基础档案，详细说明异步加载。加载失败保留基础资料并提供“重新加载档案”；没有照片时明确显示空状态和官方图库链接。请求取消和 ID 检查继续防止快速切换时错配资料。

## 数据现状

本次未改动官方数据：1,214 座全新世火山均有详情记录，20 座包含已核验照片。数量由目录动态计算，不在界面硬编码。照片覆盖率后续可独立增加。

## 验证

- Node 测试：14 项通过，包括区域视野高度、拾取去重与非实体过滤、SVG 形态差异及现有照片异步状态回归。
- Python 数据测试：8 项通过。
- Vue 类型检查及 Pages base 生产构建通过。
- Cesium 静态资源路径测试通过；`git diff --check` 通过。
- 当前自动化浏览环境没有可用 WebGL，真实 GPU 上的遮挡、密集区点击与飞行动画需在支持 WebGL 的浏览器验收，不能用构建通过代替视觉验收。

## 浏览器验收清单

1. 点击不同分类的地图图标，确认轮廓与图例一致；选中四角和名称清晰，镜头保留区域范围。
2. 在日本、印度尼西亚等密集区域点击重叠图标，确认候选列表可切换火山且路由、列表高亮、档案一致。
3. 勾选“只看有照片”，地图和列表均限制到有照片记录；取消后恢复全部。
4. 选择无照片火山，仍显示档案和地质说明；模拟详情请求失败，点击重试可恢复。
5. 手机端检查候选列表、选中提示与详情关闭按钮；确认原三种形态对照表仍可打开。

### 图标尺寸反馈修订

根据实际使用反馈缩小地图普通图标，保留 32×32px 拾取容错，因此视觉尺寸缩小不降低点击容错。选中不仅显示外围提示，山体本身也变为高亮色和白色粗描边。列表与图例的大小不随地图缩小。

用户再次确认普通地图图标宽度为 12px；选中图标宽度为 20px，继续使用亮黄色山体、白色描边与名称标签，拾取容错保持 32×32px。

## 切换后旧高亮残留修复

根因：在 `suspendEvents` 期间删除所有实体并用相同 ID 重建，EntityCollection.add 会抵消 removedEntities 中同 ID 的删除记录，导致 collectionChanged 不上报替换；Cesium visualizer 仍引用旧实体。修复为 syncMapEntities 原位更新已有实体的 billboard/label，只有筛选真正移除的 ID 才删除。回归测试使用真实 Cesium EntityCollection 验证 Marsili 与另一火山切换时对象身份保持、旧状态取消与新状态生效。实际 GPU 视觉验收仍需支持 WebGL 的浏览器。

最终尺寸按用户最新要求调整：普通图标 20px 宽，选中图标 28px 宽；点击容错窗口继续为 32×32px。此前 12px 记录仅为调整历史。
