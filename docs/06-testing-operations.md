# 06 验收、排错和维护

## 验收清单

| 项目 | 操作 | 通过标准 |
|---|---|---|
| 完整目录 | 比较清洗统计、活动快照、API、地图 | 数量一致；分页没有只返回前 1000 条 |
| 坐标 | 核对日本/意大利/夏威夷火山 | 没有经纬度颠倒；南纬西经正确 |
| 日期 | 测试 BCE、Unknown 和不确定日期 | 显示原文/明确精度，没有虚构日期 |
| 搜索/国家 | 英文、中文别名、跨国火山 | 国家多选关系正确；地图与列表同步 |
| 分享 | 打开详情 URL 并刷新 | 同一火山恢复，没有 Pages 404 |
| 图片 | 有图、无图、失效图 | 页面仍可用，作者和许可可访问 |
| 快速点击 | 连点不同火山 | 最终详情与最后选中 ID 一致 |
| 子路径 | Pages 打开 Network | Cesium worker、纹理、脚本无 404 |
| 故障 | API/地形请求失败 | 明确降级与数据日期；不伪装实时 |
| 清理 | 多次挂载/卸载地图 | Viewer/handler 被销毁，无持续堆积 |
| 安全 | 检查源码、dist 和日志 | 无数据库 secret；公网只有只读端点 |
| 访问 | 匿名调用数据库/接口 | 禁止匿名写；公共 DTO 不含日志/私密字段 |
| 手机 | 窄屏操作和详情 | 筛选/关闭可点击，不被面板遮住 |

核心自动测试覆盖坐标、日期、国家映射、分页完整性、错误状态、取消请求和只读方法限制；不写大量仅重复实现的无意义测试。
交付每阶段执行记录：命令、结果摘要、失败修复及限制。当前文档包未运行产品测试。

## 常见故障

| 现象 | 首先检查 | 修复方向 |
|---|---|---|
| 新仓库不可见 | GitHub App 仓库访问列表 | 把新仓库加入对应应用 |
| Pages 403 / deploy 失败 | Source、workflow permissions、environment | 核对 Pages/ID token 权限和 main 部署规则 |
| Vue 页面白屏 | Console、JS 404、base | Pages base 应是 /volcano-atlas/ |
| 地球空白 | WebGL、容器高度、Cesium worker | 容器尺寸和静态资源路径 |
| 地球有点无地形 | terrain 网络/token | token 和授权；显示椭球降级 |
| API 返回 HTML | Vercel rewrite 或请求到了 Pages | 独立 API origin；排除 API 路由回退 |
| CORS 报错 | OPTIONS、Origin 和返回头 | 白名单用 origin，Vary 与缓存一致 |
| catalog 数量少 | Supabase API 行数限制 | 分批稳定查询、核对快照总量 |
| Supabase 权限错误 | Data API grant 与 RLS、身份 | 分辨表级授权和行级策略；不直接关闭 RLS |
| 照片错误山体 | ID→实体匹配记录 | 人工复核坐标与名称，撤下错误照片 |
| 新数据没有显示 | 活动快照、ETag、CDN TTL | 核对版本并按策略刷新缓存 |

## 发布和恢复

发布前：固定 commit、通过必要检查、审阅数据差异和照片许可；保存上一快照 ID。
数据库更新：新快照验证后再切换指针；异常时切回旧指针，照片变更单独保留审计。
API 回退：恢复上一成功 Vercel 部署/commit；接口 v1 保持兼容。
Pages 回退：恢复上一成功 commit，重新构建和部署；不要只回退数据库却让前端 DTO 不兼容。
凭证泄露：轮换 Supabase secret、更新服务端环境并重新部署，检查提交历史；仅删除当前文件不能撤销已泄露密钥。
维护记录：目录版本、导入错误、接口错误率、图片失效、地图供应商配额。费用与告警在实际平台配置后记录。
