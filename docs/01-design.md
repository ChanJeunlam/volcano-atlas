# 01 项目设计

> 2026-10-15 架构更新：第一版确定为 Vue + CesiumJS + 静态 JSON/图片 + GitHub Pages。Vercel/Supabase 为可选后续能力；下文相关设计保留为扩展方案。每月更新由 GitHub Actions 完成，见 10-monthly-update.md。

## 目的与成功标准

用于公开浏览、地学学习和展示。访客打开网页后可旋转全球地球、搜索火山、按国家和类型筛选，点击点位查看真实资料及有来源的照片。界面默认中文，保留英文官方名称和来源链接。

第一期做到全局目录完整、主要火山有核验照片、所有火山都能打开详情；没有照片的火山明确显示“暂无已核验照片”。不承诺每座火山都有照片。

三维定义：真实地理坐标的可旋转地球，支持倾斜视角；有地形服务时查看地表起伏。第一期不制作每座火山的独立精细三维模型。地形网格不代表当前火山口形态或近期地形变化。

## 技术路线比较

| 方案 | 优势 | 代价 | 判断 |
|---|---|---|---|
| Vue 3 + CesiumJS + Vercel API + Supabase | 延续旧项目地图引擎；地球、地形、相机和拾取功能成熟 | Cesium 静态资源部署及地形 token 需要配置 | 推荐 |
| Vue + Three.js / globe.gl | 视觉表现自由，适合分布展示 | 真实地形、地理坐标和镜头需要更多定制 | 不选为首期 |
| Vue + MapLibre 地图及地形 | 地图操作直观 | 与旧 Cesium 路线不同，全球地球体验需验证 | 后续按需求评估 |

## 选定架构

浏览器下载 GitHub Pages 的 Vue 构建产物 → 调用独立 Vercel API → 查询 Supabase。
数据导入任务先下载官方目录，在本地/受控 CI 清洗与核验，再写入数据库；不在访客请求里临时抓取上游网站。
地图影像和地形由浏览器直接请求地图供应商；照片只加载详情当前可见的缩略图。

GitHub Pages 不执行服务端 API。前端必须设置完整的 Vercel HTTPS API 地址，不能请求 Pages 同域的 `/api`。

前端：Vue 3、Vite、TypeScript、Vue Router hash 路由、Pinia、CesiumJS。
后端：Vercel Node.js Functions、输入验证库、Supabase 服务端客户端。
数据清洗：Python；XML Excel 格式按真实内容解析，不能仅看扩展名。
测试：Vitest 验证核心转换/筛选/API；Playwright 验证部署路径和页面交互。
版本在实施时核对兼容性，明确锁定并提交 lockfile，不在文档里编造“最新版本”。

## 第一期开发表现

桌面左侧搜索/筛选和统计，中间全屏地球，右侧详情抽屉；手机保留地球，详情为底部面板。
点位颜色按火山形态分类，未知用中性色。不要以最近喷发年份自动生成“危险等级”。
点击点位后相机飞到火山，展示名称、国家/区域、坐标、海拔、类型、最近已知喷发、资料来源、数据版本和照片。
路由 `/#/volcano/<gvp-id>` 支持复制分享；刷新可恢复选择。国家筛选支持跨国火山的多国关系。
照片列表提供缩略图、说明、作者、许可链接和原始文件页；大图按需加载。
搜索覆盖官方名称、已验证中文名和别名；没有中文译名时直接显示英文，不自动杜撰。

## 范围边界

首期：GVP 全新世目录、地图筛选、详情、照片、静态降级目录、平台部署和文档。
二期：已核验喷发历史时间轴、GVP 活动报告、美国 USGS 通知；必须注明覆盖范围和发布时间。
三期：板块边界、专题教学、局部高精度地形。边界数据另选权威来源并记录许可。
首期不加入账号、付费、评论和预测模型。全新世收录不等于当前喷发，也不等于完整全球火山清单。

## 错误处理与性能

API 超时：一次自动重试，仍失败时加载内置已核验轻量目录，显示快照日期；详情在线不可用时明确提示。
照片失败：替代图和来源按钮；地形失败：降级椭球地球；WebGL 不支持：保留列表和详情。
快速连续点击：取消前一个详情请求，或校验响应 ID，防止旧请求覆盖当前火山。
Cesium Viewer 使用 shallowRef/markRaw 管理，避免 Vue 深度响应式代理；卸载时销毁 Viewer、事件和请求。
首屏只加载轻量地图点位，详情和历史独立请求；开启 requestRenderMode，在交互/数据变化时请求绘制。
验收性能目标在统一参考电脑上测量：目录响应压缩后 ≤1 MB、详情面板可操作，无持续内存增长；具体 FPS 在实施初期基线测试后记录。
